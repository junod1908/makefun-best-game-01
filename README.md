SKYWARDEN is an original arcade defence game where you slide a light shield to bounce falling star-shards away from a floating city. Send shards through golden rings to raise your multiplier, catch gold motes for energy, and use dash and slow time to survive 10 waves. Choose an upgrade between each wave to strengthen your defence. Move with the mouse or arrow keys, dash with Shift/Space, and hold E to slow time.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in a desktop browser (any static file server pointed at game/ works too).
